# Overview

EKA: Trouble29 is a modular offensive security toolkit developed for reconnaissance, validation, automation, and reporting during security assessments.

# Features

- Subdomain enumeration
- Directory fuzzing
- SSL analysis
- Virtual host discovery
- Passive vulnerability testing
- Service fingerprinting
- Automated reporting

# Security Checks

- SQL Injection
- Cross-Site Scripting (XSS)
- Rate limiting checks
- SSL validation
- Misconfiguration detection

# Tech Stack

- Python
- Automation
- AWS
- Linux

# Goal

The goal of EKA was to consolidate multiple offensive security workflows into a single streamlined toolkit for faster assessments and reporting.
